# HelloActions - GitHub Actions Lab

What is the purpose of the "on" section?
  - The "on" section triggers the events that tell GitHub when to run the workflow.

What does "workflow_dispatch" do?
  - This allows developers to run the workflow whenever they want.

What does "runs-on" specify?
  - Runs-on specifies the type of virtual machine environment that it will run on.

Why is actions/checkout needed?
  - Actions/checkout is needed so that whoever decides to run the workflow has the repository checked out on their local machine. This makes it so that the program has access to local files.

What does the language setup action do?
  - It makes sure the runner is set up to run the source code.

What is the difference between compiling and running the program?
  - Compiling the code turns the code into machine code in execution
  - Running the code interperets the code directly.

Where can you see the program output?
  - In the GitHub Actions tab, running the workflow, and looking at the ouutput.

What is the difference between a workflow, a job, and a step?
  - The workflow is the overall program that runs everything
  - A job is a set of steps that run.
  - A step is a task that runs within a job.
